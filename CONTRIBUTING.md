# Contributing

This repository is my personal macOS configuration, published so others can
read it and borrow from it. Issues and questions are welcome. Pull requests
are unlikely to be merged, since the configuration is tuned to one machine,
but a PR that fixes a bug or a broken assumption is still useful as a
report.

Work here follows the process in [CLAUDE.md](CLAUDE.md): every change starts
from an issue, and every PR closes one.
